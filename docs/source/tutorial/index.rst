🐣 Tutorial
===========

This tutorial takes you from an empty folder to a running Raito bot with
commands, typed arguments and role-based access. Each page builds on the
previous one, so read them in order.

By the end you will understand the two ideas Raito is built around:

- **handlers live in files, and Raito loads them for you** — no manual
  ``include_router``, and they reload as you edit;
- **features are opt-in decorators and filters** — descriptions, argument
  parsing, roles, keyboards and pagination are added a line at a time.
